BlackStack Instagram Parser

Политика конфиденциальности

Здесь описано, как настольное приложение работает с данными Google.

Доступ и назначение

При подключении пользователь выбирает таблицу через Google. Приложение использует доступ к выбранному файлу и адрес электронной почты аккаунта. Оно сверяет аккаунт, читает структуру таблицы и существующие записи, затем добавляет новые профили и сведения об источниках. Эти данные используются для проверки дублей и записи результатов.

Хранение и передача

Токен Google хранится на компьютере владельца в зашифрованном хранилище Windows. Результаты поиска сохраняются локально и в выбранной таблице. Данные, прочитанные из Google, не передаются поставщикам поиска, рекламным сервисам и поставщикам моделей машинного обучения. Приложение не использует их для рекламы, продажи данных или обучения моделей.

Управление доступом

Доступ можно отозвать в настройках аккаунта Google. Владелец может удалить локальные результаты и строки таблицы отдельно. По вопросам работы с данными можно написать на blackstackst@gmail.com.

Приложение соблюдает политику Google API Services User Data Policy, включая требования Limited Use.
